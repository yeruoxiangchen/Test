# 第三轮：可见几何错误定位（2026-10-26 UTC）

不训练模型，先验证定位信号。上一轮四个已检查HSSD对象仅作开发诊断；新增Omni200
清单按类别字典序前8类、每类UID字典序第一个对象，先固定选样，不按重建指标筛选。
这些是新的物体和采集来源，但输入是有真实扫描纹理的渲染图，不是实拍多视图测试；
Omni200已用于原论文，不能声称整个研究从未检查过它们。

新对象使用已有四张观测、两个seed、冻结原始30K权重，共16个新重建。按训练契约
对mask做bbox裁剪并同步K，FP32 DINO/FP16缓存。新输出均做相同四输入mask有界7DoF
全局拟合，沿用上一轮100步/边界/检查点/每视图保护，不做GT ICP。旧HSSD复用上轮
已经按两观测拟合的8个mesh。不同域分别报告，不用2图/4图差异解释方法因果。

只依赖输入计算定位分数：外轮廓不一致、边界邻近、原图与灰色mesh渲染RGB差异、
同裁剪同相机的直接DINO差异、由predicted mesh投影到其他输入图的RGB/DINO差异，
以及固定等权直接/跨图DINO融合。参考图DINO patch固定随机打乱为空间对应负对照。
本项目没有可靠纹理decoder，灰色渲染残差只是基线，不能直接当几何误差标签。

跨图可用性只用预测mesh自己的z-buffer、输入mask和相机判断，深度容差0.01；
没有可靠参考观测的像素标unknown。主指标在各方法共同可用、预测与观测前景重叠且
离任一轮廓>2像素的内部区域计算，128分辨率。单独报告覆盖率；不能靠忽略无支持
区域制造完整覆盖的结论。全可见区域另报告直接分数及有明确回退的融合。

先保存全部输入分数图，再在评估阶段读取GT：固定相机camera-z深度误差阈值
0.01/0.02/0.05，主阈值0.02。轮廓只在一方出现也是可见错误。隐藏表面不当作输入
能够定位的区域；本轮不声称直接衡量完整拓扑/所有表面错误。GT渲染mask与观测mask
须通过独立相机检查（IoU>=0.90），投影回放检查及正确几何零深度误差必须通过。

AUROC、AP、误差比例、AP/误差比例、top20% precision/recall，以及物体级配对差异。
另报告分数与连续射线深度误差的Spearman相关，避免把全为正例的二分类退化伪造成有效指标。
同分按分组积分；常数分数AUROC0.5、AP等于误差率。无正/无负样本标记不可定义，
不伪造分数；完整报告这些情况。先按seed平均，再按物体平均，bootstrap以物体为
单位，不能以像素或seed伪增样本量。固定方法/阈值，不按GT挑最佳权重。

额外8个正确GT几何和8个局部形变控制用于sanity，不计入自然模型结果。形变位置由
第一观测GT渲染最大内接区域确定，sigma0.12、沿顶点法向最大0.06，固定不挑效果。
明确标GT辅助构造的人工控制，不能当作可部署输入或自然错误改善证据。

最终同时报告自然重建、空间打乱控制、定位覆盖率、人工控制和运行成本。若信号
不能稳定超过边界与打乱基线，或只有低覆盖子集有效，就不进入局部latent长训。
