# 第二轮：输入一致性和全局对齐基线

2026-10-25 UTC。复用已检查的四个 HSSD 对象与两个采样 seed；属于探索性诊断，
阈值已经看过第一轮输入轮廓分数，不能称为盲测或预注册。新源码、参数和依赖绑定
在运行前封存，第一轮源码和结果保持原样。

1. 输入一致性选择：仅两张观测 mask 和已知相机；先按两视图平均 IoU 选供图 mesh。
   固定门槛为 0.80、0.85、0.90，要求每张观测均达标；在达标来源中选择平均最高者。
   无达标来源时，原样使用同对象、同采样 seed 的 real2 输出。
2. 简单几何基线：每个供图 mesh 拟合一个 7 自由度相似变换，只用两张观测 mask。
   Adam 100 步，256 分辨率，lr0.03；旋转小于25度、每轴平移小于0.15、统一缩放
   0.75—1.25。绕原始规范原点变换，保持三角拓扑和局部形状。使用与冻结渲染器完全
   相同的 CV 投影和像素中心约定。每20步在518分辨率检查轮廓；每张图的 IoU 不得
   比初始下降超过0.005，在合格检查点中选平均IoU最高者，含identity回退。
3. 始终沿用第1项原始来源选择（在本批对象为A/B/A/A），使变换前后来源身份相同。
   用修正后供图mesh在其余六个既知相机渲染，仅根据每张自己的渲染mask裁剪。
   原始两图特征原样复用，新增图FP32 DINO编码、FP16缓存；同步内参。
   与第一轮完全一致的 SS30K/SLat30K EMA、25+25步、配对噪声，共8个新mesh。
   对这一固定来源也报告门槛回退结果，不为每个门槛重选未生成的来源。
4. 报告直接全局修正后的原始两图mesh，和用它生成额外视图再次重建的mesh。
   直接修正仍是输入相机坐标中的几何，不使用GT对齐或ICP。SS旧占据指标不能用于
   已变换mesh，因此直接修正分支不报告SS IoU。
5. 最后才读取GT评估：原始规范坐标、50000点、seed20261025的CD及F@.02。
   所有对象、所有seed及门槛均报告，不只报告接受样本；显式报告接受率和额外代价。
   原有候选池的GT oracle为诊断天花板，分别给对象级和逐seed的乐观CD选择结果，
   不能把它当成可部署基线；其F分数是CD所选分支对应的F。

输入筛选只能拒绝或选择现有候选，不保证从不可见区域确定真实结构。本轮不训练。
