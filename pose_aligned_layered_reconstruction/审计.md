## 1.1 第一次实验结论

- SS occupancy IoU：`0.372916 → 0.440586`，绝对提高 `0.067670`；
- Chamfer-L1：`0.017190 → 0.013895`，绝对降低 `0.003295`，相对降低 **19.17%**；
- Chamfer-L2：`0.0008322 → 0.0005639`，相对降低 **32.24%**；
- F-score@0.01：`0.480475 → 0.548481`，提高 **6.80 个百分点**；
- F-score@0.02：`0.759795 → 0.841688`，提高 **8.19 个百分点**；
- F-score@0.05：`0.947590 → 0.967592`，提高 **2.00 个百分点**；
- Normal Consistency：`0.790882 → 0.814497`，提高 **2.36 个百分点**。

按对象先平均两个推理 seed 后：

- Chamfer-L1 为 `53 胜 / 10 负 / 1 平`，对象级 bootstrap 95% CI 为
  `[0.002327, 0.004348]`；
- F-score@0.02 为 `59 胜 / 4 负 / 1 平`，对象级 bootstrap 95% CI 为
  `[0.062060, 0.104049]`；
- Normal Consistency 为 `50 胜 / 13 负 / 1 平`，对象级 bootstrap 95% CI 为
  `[0.016970, 0.030902]`；
- seed 42/43 的 Chamfer-L1 平均收益分别为 `0.003246 / 0.003345`，
  F-score@0.02 平均收益分别为 `0.081485 / 0.082301`，总体结论不依赖单个推理 seed；
- 逐对象/seed 的 SS IoU 收益与 Chamfer-L1 收益的 Pearson 相关系数为 `0.730`，
  与 F-score@0.02 收益的相关系数为 `0.844`。

第一次实验的正式结论是：**新增 Target-LaRI/分层条件使 SS support 更准确，而且该收益已经在同一冻结
SLat30K 下显著传递到最终 mesh；它不只是 SS occupancy 指标的局部改善。** Pred→GT 与 GT→Pred
两个方向的距离同时下降，精度和覆盖率同时提高，因此也不是通过单纯收缩或膨胀 mesh 获得收益。

256 个 mesh 全部成功，父/候选均未产生 non-manifold edge。连通分量、边界边和最大连通分量占比的
变化较混合，所以当前只得出“表面几何精度显著提升”，不声称拓扑质量已经稳定改善。最大稳定退化对象
是 index 56，其两个 seed 的 SS IoU、Chamfer 和 F-score 均退化，必须保留为反例而不能筛除。

## 3. 两份输入不是两套互不相关的训练样本

每个训练样本是同一对象的一组 posed views，每个 view 包含一张 raw 图和一个 visible target mask。程序在同一 crop 下派生 masked 图，再用同一个冻结 DINOv2 ViT-L/14-register 编码两份图。

```text
同一组 raw RGB + visible target mask + K/T
  ├─ 共享裁剪后的 raw RGB → 冻结 DINO → raw patch tokens
  │                                      ↓
  │            visible mask、masked tokens、相机 → Target-LaRI
  │                                      ↓
  │                         分层深度 / 停止层 / 目标归属 / 置信度
  │                                      ↓
  │                             3D 查询与分层交点匹配
  │                                      ↓
  │                        新视图权重残差 + 新每层几何条件
  │
  └─ 同一 raw 乘 visible mask → 冻结 DINO → masked patch tokens
                                             ├─ 旧 image-token context
                                             └─ 已知 K/T 投影 → 旧聚合器
                                                                    ↓
                                                     冻结 SS30K Flow + 新条件
                                                                    ↓
                                                         SS latent → occupancy
```

raw 中的遮挡物/背景只通过分层几何预测影响新条件，不直接成为 TRELLIS appearance context。masked 只保留当前可见的目标片段；目标被遮挡的像素为黑色，不用干净完整图替代。完整目标几何只用于训练监督。

共享预处理保存 crop、原图尺寸和 affine；K 使用 `K_feature = source_to_feature_affine @ K_source`。特征为每视图 `1369 × 1024`，visible mask 为 `518 × 518`。旧 SS 全局 context 只由 masked tokens 展平并确定性截取，最多 4096 tokens。代码也能构造原形式的 SLat per-view context，但尚未执行 SLat 推理。

比较“零初始化等价”时，比较的是**相同已预处理输入**下的模型输出。新 crop margin 默认 1.35，不声称新的图片预处理与旧项目所有历史预处理配置完全一致。

## 4. 分层头与查询条件

默认 L=5。在每视图 37×37 patch 网格预测：

| 输出 | 形状 | 含义 |
| --- | --- | --- |
| depths | V,L,37,37 | 正相机前向深度，沿每根射线严格递增 |
| stop_logits | V,L+1,37,37 | 有效交点数，类别 0…L |
| target_logits | V,L,37,37 | 每个交点是否属于目标 |
| confidence_logits | V,L,37,37 | 对交点深度的可靠程度 |

输入 raw 和 masked patch tokens、可见 mask、16 维归一化 K/w2c 信息；masked 可见区域跨视图池化出目标描述符。连续几何和离散分类使用两个独立卷积 tower，各 3 层，hidden channels=256。softplus 保证第一层正深度与相邻层正间距。分层头从随机初始化监督训练，非官方 LaRI 权重初始化。

SS 仍使用 16³ 个 canonical 3D 查询。每个查询投影到每个输入 view，比较 query z-depth 与有效的目标交点，生成 12 个特征：目标/非目标/任意表面支持、可见目标支持、隐藏目标支持、前方遮挡物、前方自由空间、目标深度有符号/绝对残差、匹配层序、置信度、可见 mask。

实现中的关键约束：

1. 分层预测网格采用 half-pixel 中心映射，不把 518 图像的 align-corners 网格直接用于 37 网格。
2. 层图采样按有效概率加权，防止无效层的占位深度污染边界插值。
3. 非目标层可以表示前方遮挡，但不能作为目标表面支持。
4. 层证据保留绝对置信度，不把极低支持度重新归一化成完整强度。
5. 新 view gate 的末层和 24 个新 block projection 初始为零；不添加手工固定的强制遮挡门控。
6. CFG 正分支使用新层条件；负分支沿用父模型无条件路径，包括父每层投影已学习的 bias。推理缓存不随扩散步变化的条件。

## 5. 训练协议与标签来源

阶段 A：训练 Target-LaRI。冻结 DINO，loss 为有效交点上的 Smooth L1 depth、stopping CE、target ownership BCE，以及权重 0.1 的 depth-error-calibrated confidence BCE。深度单位必须与归一化物体坐标中的相机平移一致。

阶段 B：冻结 SS30K 和 Target-LaRI，只训练 `layer_encoder`、`view_gate`、`layer_block_condition` 共 56 个参数张量。使用父 sampler 的 flow-matching target，t 为 sigmoid(N(1,1))；每步同步计算父模型 loss 作为诊断，不作为蒸馏监督。可选择 oracle 层或预测层。预测层训练只需要真实 SS latent，不必提供分层 GT；oracle 必须提供层标签。

GT 层输入应来自完整场景的 depth peeling / ray intersection：分别保留目标与其他物体交点，合并排序后记录目标归属与 stopping index；不是仅有首个可见深度。本目录提供合并逻辑和解析盒体测试场景，尚未提供面向大型资产库的完整 mesh 场景合成与批量 depth-peeling 渲染器。

代码当前为单 GPU 研究入口，支持步数、梯度裁剪、保存 checkpoint；阶段 B 支持混合精度、梯度累积和 gradient checkpointing。没有 DDP、正式 resume 或新模块 EMA。SS30K EMA 是冻结父权重，与新模块是否使用 EMA 是两件事。

## 3.1 问题定位与修正

原始 30K 仅用 K/T 做显式投影；Target-LaRI 还会把 K 和 `w2c [R|t]` 的数值直接送入相机
MLP。正式训练样本使用 `camera_forward_sign=-1`、等效负 `fy`、物体中心深度约 2，而初版
YCB-V 测试使用 `camera_forward_sign=+1`、正 `fy`、物体中心深度约 4.08--4.92。两套矩阵
可以描述相同的像素投影，但对相机 MLP 并不等价，因此初版测试属于相机元数据分布外输入。

修正采用两层适配，且不修改冻结父模型、SLat30K 或已有 checkpoint：

1. 用 `diag(1,-1,-1,1)` 将 CV `+Z` 相机变换为训练采用的等价 GL `-Z` 表示，同时反转
   `fy`。该变换保持每个三维点的像素投影不变。
2. 只对 Target-LaRI 相机 MLP 的平移元数据做半径适配，使目标中心深度为训练常见值 2；得到
   分层深度后再恢复每个视图的真实中心深度。父 SS、逐点投影和 SLat 仍使用真实物理相机。

`no_adapters` 模式与旧父 SS 的 occupancy 完全一致（六组 IoU 均为 1.0），证明相机重写没有
暗中改变原始 30K 路径。

1）：

|---|---:|---:|---:|
