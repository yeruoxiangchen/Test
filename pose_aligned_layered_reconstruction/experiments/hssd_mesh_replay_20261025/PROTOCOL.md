# One-case mesh replay, 2026-10-25

固定DepthBalance16柜架hssd_102344049_i083，全局index=2，seed=42。
先验证uniform/balanced原始SS坐标完全一致。原134项冻结源码、协议、数据和结果保持不变。
输入仅保存冻结SLat的观测allowlist；GT仅用于生成后评分，不进入模型。

GPU首次按原函数生成噪声，保存实际稀疏坐标及噪声张量；所有重复均从该文件重建新的SparseTensor。
同一进程完整25步采样和解码两次；独立进程第三次。复用同一SLat30K EMA和原decoder，
相同bf16采样、CFG、相机和原生mesh坐标，安装原有已绑定的channelwise显存补丁。
每次使用新的CFG缓存和稀疏输入，不通过修改seed、精度或模型来强求一致。

保存每次Flow输入/输出、Euler更新、归一化后latent；首次Flow调用记录主要内部模块输出。
保存decoder主要模块输出、raw mesh、to_trimesh输出和保存后重读结果。
额外用第一次的固定latent（只复制坐标/特征，清空派生稀疏缓存）重复解码两次，
单独比较它们和第一次端到端解码；记录缓存键差异，不能把缓存不同的回放误称完全相同运行状态。
观测快照只detach/copy到CPU，不替换模型输出或采样器方程；记录权重版本、模型模式、环境和RNG摘要。

预先限制三个完整采样、两次额外解码；每个worker最长600秒，每条trace最多2GiB张量。
任何失败停止，不删除半成品；重试写入新attempt，完成阶段验证后复用。一个worker失败不会启动下一worker。
该诊断允许“不完全一致”作为正常科学结果，不将不一致视为必须修到通过的门槛。
第一次出现差异的模块是定位范围，不自动等价于某一个CUDA算子有bug。

此处只检验一个物体、一个噪声，不能推导所有对象的噪声上界、泛化性能或方法收益。
若全程精确一致，只说明本次条件下未复现旧差异；旧结果的历史中间张量缺失，不能据此宣称旧问题已修复。
