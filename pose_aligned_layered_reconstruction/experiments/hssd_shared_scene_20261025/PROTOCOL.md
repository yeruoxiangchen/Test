# 冻结协议与下一阶段决策

日期：2026-10-25 UTC。当前任务为 SharedScene4 数据/基线建立，未提出已验证的新方法。

## 待回答的问题

同一组场景 RGB 图像在多个实例之间共享时，已有物体生成模型是否仍能生成正确的实例几何？错误主要发生在可见表面、被其他物体挡住的表面，还是世界坐标组装中？本轮把相机与实例坐标作为已知条件，以分离重建误差和前端定位误差。

## 固定内容

HSSD `102344049`，旧 pilot 索引 `[0,5,6,7]`，实例 `[76,75,80,65]`。这是同一餐桌区域的既有编码物体，选择发生在新预测产生之前，不按新指标挑选。12 帧公共连续轨迹，所有目标统一使用 `[0,4,7,11]`；输入边长 518，水平视场角 75 度。完整场景渲染，保留其他实例形成的遮挡。

旧 canonical mesh/SS/SLat 以文件 SHA 绑定；禁止重编码、调整 GT、删去失败目标、为不同模型独立选视图。SS 仅保存和评估预测占据坐标，SLat 条件只读取允许的 RGB 特征与相机字段。隐藏 GT 深度与 amodal mask 存在 `evaluation_gt/`，不进入模型条件。

显式提供的特权输入是：已知相机、可见实例 mask、GT 推导的 canonical frame（含中心、尺度和方向）。因此不能宣称纯 RGB 输入的端到端结果。旧训练对象的新共享视角也不能作为独立测试集。

SS 两种冻结权重为父模型 `yxc30k` 和旧 `occluded_appearance_control`。同一个 SLat30K，25 步，CFG 5，区间 `[0.5,1]`，rescale_t=3，seed `[42,43,44]`。噪声按原对象索引和 seed 固定，SLat 每坐标取相同 master noise。使用已完成算子审计的 `FixedNative`；内存优化仅复用旧已验证 mesh 解码实现。

## 坐标与评估

Habitat world Y-up → Blender Z-up 使用同一已知固定旋转。相机为 OpenCV w2c；canonical 外参须移除统一尺度对旋转矩阵的污染，使 R 正交、det(R)=1，并同步缩放平移/深度单位。实际世界点与 canonical 点投影须一致。

独立光栅化与 Blender 可见实例掩码 IoU 须≥0.95；视野中深度超过 0.08 米或没有命中几何的像素比例须≥0.95。后者只是近距离几何的粗检查，不是完整可行走路径或相机碰撞证明。每个对象至少在一张公共输入中可见；不要求每张都可见。

还比较实际归档 GT mesh 经 canonical→world 变换后的顶点与 Blender 对应实例的顶点，双向最近距离最大值须≤0.0001 米。此项检查物体坐标与真实场景几何的对应关系，补充相机矩阵自身的数学一致性检查。

本轨迹中长凳仅约 0.7%–4.5% 投影面积可见；凳子在两帧完全不可见。保留这些情况，并按可见性分项审阅。几乎没有外观证据的对象存在形状歧义，其失败本身不能证明某个架构无效。

canonical 预测 mesh 使用 `transform_pose=False`，直接对 GT 计分。禁止 ICP、独立旋转/平移/尺度拟合、平滑、删连通分量。world mesh 仅应用同一个已知 canonical_from_world 的逆变换。CD、F@0.02 为 canonical 单位，不能当米解释。

报告 20,000 固定种子表面采样的双向 CD、F-score、法向一致性、连通分量等。GT 表面再分为至少一视图可见、始终不可见且被外部实例遮挡、其他未观测；各组给出 GT→预测距离与召回率，空组为 null。视深容差 0.02 canonical，属于光栅近似分组。预测表面在观察到的第一场景表面之前的比例作为自由空间违反诊断，不命名为碰撞体积或完整场景穿插率。

每对象、每 seed 都生成同相机 GT/父模型/外观对照对比图。组合 GLB 展示已知布局下的四个生成物体，不宣称自动恢复尺度、姿态或场景布局。结果必须完整覆盖 24 个 mesh 后汇总，不能只平均成功案例。方法间训练经历不同，本次不做新贡献的因果归因或显著性结论。

## 当前 LaRI 与后续设计

依据 2026-10-25 固定内核的 72-mesh 公平复核，当前 LaRI balanced 仍未超过同容量外观对照。保留实验和权重，暂停本配置追加训练/扩量。新的共享场景输入实验不依赖 LaRI。

先看本轮失败分布和真实 mesh。若可见面重建已经失败，优先核对共享视图上的特征投影和实例分离；若可见面稳定、隐藏面主要受损，再限定一个“共享场景观测与不确定性条件”的新模块，区别目标可见表面、其他实例已占据区域和未知空间。未知空间不直接标成空，不将预测完整深度当成硬表面真值。

随后先用理想观测几何确定可改善的上限，再使用仅从 RGB 估计的观测几何/相机及置信度；在冻结父骨干上做短拟合和相同容量外观对照。只有这种配对机制实验通过，才增加独立场景/对象、预测实例前端并开展正式训练。该流程是下一阶段计划，本次未实现或验证新模块。

GENA3D 必须使用预测补全前端，并明确坐标协议后才进入真实对照。GT 补全只能另标为特权上限；当前不提供伪装成官方完整方法的替代输入。
